# Hack Your Own Adventure
A group project created by myself and 3 peers which focused on showcasing the general knowledge we had gained during our Adversarial & Cybersecurity Mindset class. 

## The Game
### What it is
We based it off of the choose your own adventure books, where the reader gets to decide what path to take in the story. In this story, you can choose several different ways to hack into a bad company i.e. social engineering, web exploitation, or phishing. 

### How to start
To start the game, download all the files, open a terminal, go to the downloaded folder, and stype into the terminal

```
python .\intro.py
```

Then answer the questions as it walks you through the game.
